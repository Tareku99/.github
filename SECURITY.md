# Security policy

On the affected repository, open **Security → Advisories → Report a vulnerability** to submit a private report if the option is available. If the repository lists a maintainer’s private contact channel, you can also use that channel. Keep vulnerability details, credentials, and reproductions out of public issues and discussions.

Include the affected repository, commit or release, deployment environment, impact, and the minimum steps needed to reproduce the problem. Use test accounts and remove real secrets from any evidence.
