# Support

Start with the project README and search the repository’s existing issues. Use Discussions for general questions where enabled, or open an issue for a reproducible bug or a feature request.

Include the project version, host OS and architecture, install method, expected behavior, and relevant logs. For hardware projects, include the model, adapter, and connection type. Remove credentials, tokens, and private details from logs and configuration before posting.

Report vulnerabilities using the repository’s [security policy](https://github.com/Tareku99/.github/blob/main/SECURITY.md).
